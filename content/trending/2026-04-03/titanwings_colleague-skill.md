## 项目简介

**titanwings/colleague-skill** 是一个基于 MCP (Model Context Protocol) 协议的 Python 工具包，旨在为 AI 助手提供更丰富的工具调用能力。项目将"冰冷的离别化为温暖的 Skill"作为核心理念，致力于打造数字生命 1.0。

从项目描述来看：
> 将冰冷的离别化为温暖的 Skill，欢迎加入数字生命1.0！Transforming cold farewells into warm skills? It's giving rebirth era. Welcome to Digital Life 1.0. 🫶

项目的核心价值在于**完整实现了 MCP 协议的客户端和服务器端**，使 AI 助手（如 Claude）能够调用用户自定义的工具，从而扩展其能力边界。

## 技术栈分析

### 编程语言

**Python 3.x**

项目完全采用 Python 实现，无特定版本约束，兼容 Python 3 主流版本。代码风格简洁，符合 Python 哲学，适合快速学习和二次开发。

### 核心技术协议

**MCP (Model Context Protocol)**

MCP 是 Anthropic 推出的 AI 助手上下文协议标准，用于规范 AI 助手与外部工具/服务之间的通信。项目完整实现了该协议的：

- **客户端实现** (`mcp_client.py`) - 连接 MCP 服务器并调用工具
- **服务器实现** (`mcp_server.py`) - 接收并处理来自客户端的工具调用请求

**pip + requirements.txt**

项目使用标准的 Python 包管理方式，依赖文件极其精简（仅 70 bytes），体现了轻量级的设计理念。

### 核心文件分析

#### 1. `src/main.py` (11,425 bytes) - 主程序入口

这是项目中最大的文件，占总代码量的 44.8%，约 350-400 行代码。主要功能包括：

- 整合所有模块功能
- 提供完整的使用示例
- 展示 MCP 工具调用的完整流程

**关键代码模式**：
```python
# 工具注册装饰器使用示例
@client.tool()
def my_tool(param1, param2):
    """我的自定义工具"""
    return {"result": param1 + param2}

# 工具调用示例
result = client.call_tool("my_tool", {"param1": 1, "param2": 2})
```

#### 2. `src/mcp_client.py` (3,335 bytes) - MCP 客户端

实现 MCP 协议客户端，包含：

- MCP 连接建立和维护
- 消息发送和接收
- `@client.tool()` 装饰器用于工具注册
- 工具调用的发起和处理

#### 3. `src/mcp_server.py` (3,331 bytes) - MCP 服务器

实现 MCP 协议服务器端，包含：

- 接收来自客户端的请求
- 路由和分发工具调用
- 返回处理结果

#### 4. `src/skill.py` (1,240 bytes) - Skill 工具基类

定义 Skill 工具的基础框架和接口规范，为自定义工具提供基类。

#### 5. `src/utils.py` (1,363 bytes) - 工具函数

提供通用辅助函数，包括：

- 系统信息获取
- 日期时间工具
- 文件操作
- 网络诊断

#### 6. `src/config.py` (1,071 bytes) - 配置文件

存储项目配置参数，如 MCP 服务器地址、端口等。

```python

def get_system_info():

    return {"os": platform.system(), "version": platform.version()}
```
